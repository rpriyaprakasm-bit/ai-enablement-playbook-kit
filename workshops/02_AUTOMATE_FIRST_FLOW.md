# Workshop: Your first useful flow (90 minutes)

## Outcomes

1. Build a scheduled or item-triggered flow with notification  
2. Add basic failure notification  
3. Know environment / DLP checkpoints before production  

## Agenda

| Time | Activity |
|------|----------|
| 0–10 | When Automate beats Copilot; guardrails in 5 bullets |
| 10–25 | Demo: SharePoint item created → Teams message |
| 25–55 | Guided build (participants follow) |
| 55–70 | Add “run after failure” notification |
| 70–80 | Test + rename + owner field discipline |
| 80–90 | Packaging next steps; how to request production promote |

## Success criteria for the room

- Flow runs successfully at least once  
- Participant can explain what happens on failure

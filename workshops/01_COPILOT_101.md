# Workshop: Copilot 101 for business teams (60 minutes)

## Outcomes

By the end, participants can:

1. Run three approved Copilot scenarios on their own content  
2. Spot at least two anti-patterns  
3. Know how to submit an automation idea to the intake hub  

## Agenda

| Time | Activity |
|------|----------|
| 0–5 | Purpose, data sensitivity reminder |
| 5–15 | Demo: summarize a status doc → risks & asks |
| 15–30 | Hands-on: participants paste **non-sensitive** sample text |
| 30–40 | Demo: meeting notes → action list |
| 40–50 | Hands-on + pair share |
| 50–55 | When to use Automate instead; show intake link |
| 55–60 | Feedback form (1 metric + 1 question) |

## Materials

- Sample status paragraph (fictional)  
- Prompt tip sheet (from Copilot playbook)  
- Intake form URL  

## Facilitator notes

- Ban real Restricted data in the room.  
- If Copilot is unavailable for some users, run a shared demo account only for projection.

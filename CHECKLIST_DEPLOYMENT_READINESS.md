# Deployment readiness checklist

Use before promoting a citizen or Value Hub solution to production use.

## Ownership

- [ ] Primary owner named  
- [ ] Backup owner named  
- [ ] Support expectation documented (best effort vs business hours)  

## Security & data

- [ ] Sensitivity rated  
- [ ] DLP-compatible connectors  
- [ ] No embedded secrets  

## Quality

- [ ] Happy path tested with sponsor  
- [ ] Failure path notifies someone  
- [ ] Short SOP or readme linked  

## Platform

- [ ] Correct environment  
- [ ] Licensing confirmed  
- [ ] Intake / backlog item updated to **Deployed**  

## Enablement

- [ ] Users know how to run / request access  
- [ ] Pattern shared with CoP if reusable
